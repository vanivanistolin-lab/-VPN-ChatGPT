# VPN ChatGPT

Windows x64: помощник обновления вкладок ChatGPT после подключения Happ, расширение Chrome с мини-окном и автозапуск EXE.

## Установка
1. Скачайте `dist/ChatGPTRefresh-Setup.exe` и запустите его один раз.
2. Программа копирует себя в `%LOCALAPPDATA%\ChatGPT-Happ`, создаёт ярлык в автозагрузке и запускается в фоне. После успешной установки автоматически открывается этот README.
3. Установщик сохраняет расширение в `%LOCALAPPDATA%\ChatGPT-Happ\extension` и регистрирует локальный помощник состояния VPN.
4. Установщик автоматически открывает Chrome на странице расширений и папку с файлами. Включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите открытую папку `extension`. Chrome требует выполнить это подтверждение вручную.
5. Нажмите значок расширения: в мини-окне доступны статус VPN, количество вкладок ChatGPT и ручное обновление.

Само скачивание EXE не запускает установку. Добавление расширения в Chrome выполняется вручную. Папку установленного расширения перемещать нельзя.

## Поведение и ограничения
- Расширение обновляет только вкладки `chatgpt.com` и `chat.openai.com` примерно через 3,5 секунды после обнаружения VPN.
- Локальный помощник только читает состояние сетевого адаптера Happ/Xray. Состояние адаптера не гарантирует доступность сервера VPN.
- VPN и Happ эта сборка не отключает. Она не содержит подписок, ключей VPN или скачивания сторонних программ.
- EXE также содержит прежний способ обновления активного окна браузера; раньше он работал ненадёжно. Для обновления вкладок используйте расширение. После его установки можно завершить фоновый EXE через значок возле часов: локальный помощник расширения Chrome запускает самостоятельно.
- Сквозная проверка новой установки после перезагрузки пока не выполнена. EXE не подписан цифровой подписью.

## Сборка
Запустите `build.ps1` в Windows PowerShell. Используются встроенный компилятор .NET Framework и системные библиотеки; интернет для сборки не нужен.

## Удаление
Закройте EXE через его значок возле часов. Удалите ярлык `ChatGPTRefresh.lnk` из папки автозагрузки (`shell:startup`), расширение из Chrome и ключ `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.chatgpt_happ.status`. После этого можно удалить `%LOCALAPPDATA%\ChatGPT-Happ`, если эта папка не используется другими установленными ранее скриптами.
