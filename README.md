# VPNKRUT-SUB 3.0

Самостоятельный VPN-клиент для Windows x64: единый MSI, встроенные sing-box 1.14.4 и Wintun 0.14.1, общий каталог бесплатных серверов и локальная админ-панель. Happ, INCY и v2rayTun устанавливать не требуется.

## Установка и подключение
1. Скачайте VPNKRUT-SUB-3.0.1-Setup.msi из Releases и установите.
2. Откройте ярлык VPNKRUT-SUB на рабочем столе. При первом запуске прокрутите и примите условия использования.
3. Выберите сервер из списка и нажмите «Подключить выбранный сервер».
4. Подтвердите запрос Windows на запуск встроенного движка с правами администратора. Создание туннеля требует этих прав.

Каталог включён в установщик для первого запуска без доступа к GitHub и обновляется с GitHub при открытии окна, по кнопке и каждые 60 секунд, пока окно открыто. Географических ограничений в коде программы нет; доступность GitHub и конкретных серверов зависит от сети.

Если уже работает другой распознанный VPN, программа не выключает его и не запускает второй туннель. На этом компьютере действующий Happ во время разработки не отключался. Для теста нового подключения пользователь должен самостоятельно завершить другое соединение.

У встроенного движка отдельный значок возле часов. Закрытие его окна оставляет соединение в фоне. Кнопка отключения касается только соединения VPNKRUT-SUB и требует подтверждения. Закрытие основного окна или выход из помощника не выключают внешний VPN или встроенный движок.

## Общий каталог и админ-панель
Alt+A открывают локальную панель для вручную добавленных ключей. Локальный пароль интерфейса не является авторизацией GitHub и не даёт права менять общий каталог.

Введите название сервера и VPN-ссылку. Локальный каталог шифруется Windows DPAPI. Чтобы другие пользователи получили серверы, нажмите «Опубликовать для всех». Будут опубликованы только записи этого каталога; программа не читает VPN-ключи других людей.

Для публикации из админки нужен fine-grained токен аккаунта vanivanistolin-lab с разрешением Contents: Read and write только для репозитория -VPN-ChatGPT. Токен создаётся владельцем в настройках GitHub и вводится в отдельном окне публикации. Его можно сохранить зашифрованным в своей учётной записи. Токен не входит в установщик, каталог или исходники. Не отправляйте токен в переписку и не публикуйте его в репозитории.

Общий каталог: https://github.com/vanivanistolin-lab/-VPN-ChatGPT/blob/main/catalog/servers.json
Все ключи в нём общедоступны. Добавляйте только собственные ключи, которые разрешено раздавать бесплатно. Пользователям не нужно вводить токен GitHub для получения списка.

## Поддержка ссылок
Встроены VLESS (TCP, WebSocket, gRPC, HTTPUpgrade; TLS и Reality), VMess, Trojan, Shadowsocks без внешних плагинов, Hysteria2 и TUIC. HTTPS-подписка со списком ссылок или base64 раскрывается перед выбором сервера.
XHTTP, SSR, WireGuard share-ссылки, произвольные конфигурационные JSON и нестандартные плагины пока не поддерживаются. Ссылки с отключённой проверкой TLS отклоняются. Проверка формата не подтверждает работоспособность сервера.

## Проверки и ограничения
Пройдены тесты адресов ChatGPT, локального шифрованного каталога, публичного JSON, входа администратора и формирование конфигураций. Девять конфигураций и добавленный владельцем сервер приняты командой sing-box check без старта туннеля.
Подключение к реальному серверу, проверка внешнего IP и работа после перезагрузки пока не проверены: существующий VPN не отключался. Релиз предварительный.
Обновляется только активная вкладка ChatGPT через UI Automation/MSAA. При недоступности адреса или кнопки обновление не подтверждается. Готовность загрузки сайта не проверяется.
Работает на Windows x64; ARM64-драйвер в пакет не входит. Подпись VPNKRUT-SUB тестовая и доверена только на компьютере автора. На другом компьютере возможны предупреждения Windows/SmartScreen.

## Данные
Локальные настройки, зашифрованный каталог и диагностический журнал хранятся в %LOCALAPPDATA%\ChatGPT-Happ. Закрытые ключи других VPN-программ не собираются.
Для запуска выбранного сервера создаётся временная конфигурация с доступом только текущему пользователю, администраторам и SYSTEM. Движок удаляет её при нормальном завершении; не публикуйте папку sessions.

## Удаление
Используйте Параметры Windows → Приложения → VPNKRUT-SUB. Если встроенный VPN работает, сначала отключите только его вручную, чтобы не прерывать соединение во время удаления или обновления. Настройки пользователя сохраняются. Другие VPN-приложения и их профили установщик не удаляет.

## Сборка и компоненты
fetch-engine.ps1 загружает только официальные sing-box и Wintun и проверяет SHA-256. build.ps1 собирает EXE системным компилятором .NET Framework. src/build_msi.py (Python 3.12 / msilib) создаёт полный MSI.
Лицензии и ссылки на исходники сторонних компонентов: THIRD-PARTY.md, engine/LICENSE-sing-box.txt, engine/GPL-3.0.txt и engine/LICENSE-wintun.txt. Вендорские бинарные файлы не изменены.
